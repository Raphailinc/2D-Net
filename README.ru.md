# 2D Net

[English](README.md) · [Русский](README.ru.md)

**Архивный учебный проект.** Сохранён как часть истории обучения. Актуальные backend-проекты — в [профиле](https://github.com/Raphailinc).

Браузерный учебный проект: развёртка кубика Рубика на плоскости.

## Возможности

- Повороты граней кнопками и стандартной нотацией.
- Выполнение последовательностей ходов.
- Перемешивание и сброс кубика.

## Локальный запуск

```bash
python -m http.server 8000
```

## Условия запуска и границы проекта

Откройте http://localhost:8000 или index.html напрямую. Это двумерная визуализация без сборки, зависимостей и автоматических тестов.
